About DevToolBox

DevToolBox is a collection of fast, simple, browser-based developer utilities. The goal is to make common developer tasks — formatting JSON, decoding a JWT, generating a UUID, hashing text — easy without requiring uploads, accounts, or a backend.

All 19 tools run entirely client-side using plain HTML, CSS and JavaScript. Nothing you type is sent to a server.

Why browser-only?

Sensitive data — tokens, credentials, internal config — often ends up pasted into online tools. Keeping everything client-side means your data never leaves your machine.
