# DevToolBox V4

A collection of 19 free, fast, browser-only developer tools: JSON, JWT, Base64, UUID, timestamps, SQL, regex, diff, hashing, passwords, colors, case conversion, word counting and Markdown preview.

## What's new in V4

- Fixed 6 tools that were completely broken due to corrupted string literals (CSV→JSON, JSON→CSV, SQL Formatter, Regex Tester, Diff Checker, UUID Generator)
- Added dark mode with system-preference detection and persistence
- Added a mobile-friendly hamburger navigation
- Added 6 new tools: Hash Generator, Color Converter, Password Generator, Case Converter, Word Counter, Markdown Previewer
- Added category filter tabs and improved search on the homepage
- Added drag-and-drop file loading, Ctrl/Cmd+Enter shortcut, and copy-button feedback
- Redesigned styling: refined color system, spacing, and responsive behavior

## Deploy

Static site — upload all files to any static host. Replace `example.com` in `robots.txt` and `sitemap.xml` with your real domain before launch.
